# Raksha Setu — Disaster Relief Management System

Raksha Setu is a disaster relief management system designed to support the organisation of relief activities during emergencies. It helps manage information about affected people, relief requests, and available supplies in one system.

## Features

- **Affected People Registration:** Register and maintain records of people affected by disasters.
- **Relief Request Management:** Record and manage requests for assistance.
- **Supply Tracking:** Maintain information about relief supplies.
- **CRUD Operations:** Create, view, update, and delete records.
- **Data Management:** Organise disaster relief information for easier access and management.

## Tech Stack

- **Programming Language:** C#
- **Framework:** .NET
- **Development Environment:** Visual Studio
